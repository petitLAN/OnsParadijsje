Modular mode: cards are rendered from assets/config.js. Reorder, remove, duplicate, or add frames without touching the layout HTML.

Local edits stay in this browser until you export the config.

Interface frames

Move, hide, remove, or replicate the cards. Use “Download config.js” afterwards to save your new order permanently.

How this works

  1. Each card is one frame object in the layout array.
  2. Replicating a card creates a new frame with the same type and content.
  3. Changing width controls its grid span: span-3, span-4, span-6, span-8, or span-12.
  4. All text/data lives in the content block.
